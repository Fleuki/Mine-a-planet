# Mine a Planet 🪐

2D-игра для **Яндекс.Игр** в жанре idle/gacha, вдохновлённая Roblox «Mine a Planet».
Крутите рулетку, получайте дронов-буров разной редкости, ставьте их на планету,
добывайте руду, продавайте, прокачивайтесь и улучшайте планету — она визуально
меняется и даёт более ценную руду.

Написано на чистом **HTML5 + Canvas + ES-модулях**, без сборщиков и рантайм-зависимостей.
Весь визуал (планета, дроны, руда, эффекты) рисуется процедурно на canvas — никаких
готовых стикеров.

## Возможности

- 🎰 **Рулетка дронов** — 6 редкостей (Обычный → Мифический), анимированный барабан, честные шансы с учётом «Удачи».
- 🤖 **16 дронов** — у каждого свой тип бура (шнек, сверло, пила, лазер, спарка, квад) и своя добыча.
- 🪐 **10 ярусов планет** — от «Пустоши» до «Пустоты», каждая перерисовывается и повышает множитель ценности руды.
- 💎 **12 видов руды** — открываются по мере прокачки планеты.
- 🌳 **Дерево прокачки** — 3 ветки (Добыча, Логистика, Удача): скорость, ценность, хранилище, доки, удача, мульти-ролл, авто-продажа, оффлайн-добыча.
- ⚗️ **Машина слияния** — сплавляй 3 дрона одной редкости в 1 дрона выше рангом; мифики перерабатываются в гемы.
- 🏆 **Достижения** — 17 целей с наградами (деньги/гемы), авто-разблокировка и уведомления.
- 📅 **Ежедневные награды** — 7-дневная серия входов с гемами, деньгами и бустом.
- ☄️ **Космические события** — метеоритный дождь, солнечная вспышка, аномалия, золотая лихорадка: перекрашивают небо, дают временный бонус (×2–×3 доход / скорость / удача) и гемы по завершении.
- 💠 **Индикация руды** — рядом с каждым дроном светится самоцвет той руды, которую он сейчас добывает.
- ⚡ **Ускорители** — ✕2 к доходу за просмотр рекламы или гемы; «удачный спин» за гемы; удвоение оффлайн-дохода за рекламу.
- 🔊 **Процедурный звук** — SFX и фоновая музыка синтезируются в WebAudio (без аудиофайлов), с переключателем.
- 💾 **Сохранения** через Yandex SDK (облако для авторизованных, иначе localStorage).
- 🌙 **Оффлайн-доход** — дроны работают, пока вас нет.
- 📱 Адаптивный интерфейс (лендскейп/портрет, мобильный тач).

## Структура

```
src/
├── index.html          # каркас + подключение Yandex SDK
├── css/style.css       # дизайн-система интерфейса
└── js/
    ├── config.js       # весь баланс: руда, дроны, планеты, апгрейды
    ├── state.js        # игровая логика и экономика
    ├── sdk.js          # обёртка Yandex Games SDK (+ фолбэк)
    ├── audio.js        # процедурный звук и музыка (WebAudio)
    ├── render.js       # рендер мира (планета, доки, дроны)
    ├── sprites.js      # иконки дронов/планет для UI
    ├── background.js   # анимированный космический фон
    ├── particles.js    # частицы и всплывающий текст
    ├── ui.js           # HUD, модалки, рулетка, дерево прокачки
    └── main.js         # бутстрап + игровой цикл
```

## Локальный запуск

Из-за ES-модулей нужен HTTP-сервер (не `file://`):

```bash
cd src
python3 -m http.server 8080
# открыть http://localhost:8080
```

Вне Яндекса SDK недоступен — игра автоматически переключается на localStorage
и работает без рекламы. Баланс можно править в `src/js/config.js`.

## Публикация в Яндекс.Играх

1. Заархивируйте **содержимое папки `src/`** (чтобы `index.html` был в корне zip):
   ```bash
   cd src && zip -r ../mine-a-planet.zip .
   ```
2. Загрузите zip в [консоль разработчика Яндекс.Игр](https://games.yandex.ru/console/).
3. SDK (`https://yandex.ru/games/sdk/v2`) подключается со страницы игры на Яндексе —
   отдельно класть его в архив не нужно.

## Тестирование визуала (dev)

Быстрый прогон в headless-браузере (нужен Playwright):

```bash
npm install
node tools/visual-test.mjs   # скриншоты основных экранов в tools/shot_*.png
```

---

Баланс и контент легко расширяются: добавьте запись в массивы `DRONES`, `ORES`
или `PLANETS` в `config.js` — остальное подхватится автоматически.
