# assets/

Optional PNG overrides. **Everything here is optional** — any id that has no
file keeps drawing itself procedurally, so a missing file is a silent fallback,
never a crash.

## Куда что класть

| Файл | Что это | Требования |
|---|---|---|
| `drones/<droneId>.png` | Спрайт дрона | **Прозрачный фон обязателен.** Пропорция ~4:5, дрон по центру, бур вниз |
| `planets/<name>.jpg` | Карта поверхности планеты | **Развёртка ~2.2:1, бесшовная по горизонтали.** Не «лицо» планеты — движок её прокручивает. Альфа не нужна, поэтому **JPEG предпочтителен** — вчетверо легче PNG |
| `ores/<oreId>.png` | Иконка руды | Прозрачный фон, 1:1 |

`<droneId>` и `<oreId>` — это `id` из `src/js/config.js` (например `scout`,
`dust`), а не отображаемые русские имена.

## Как подключить

Пути прописываются в `src/js/config.js`:

```js
var DRONE_ART  = { scout: "assets/drones/scout.png" };
var PLANET_ART = { 0: "assets/planets/wasteland.png" };   // ключ — индекс тира
var ORE_ART    = { dust: "assets/ores/dust.png" };
```

Дальше всё само: `preloadArt()` в `main.js` подгрузит, `getArt()` закэширует,
рендер подставит.

## Проверь перед коммитом

- **Альфа настоящая?** Открой на тёмном и на светлом фоне. Белая кайма по
  контуру или шахматка в пикселях = фон запечён, нужен хромакей.
- **Планета бесшовна?** Приставь картинку к её же копии — стык не должен
  читаться. Движок гоняет её по кругу, шов будет проезжать через диск.
- **Читается мелким?** Дрон на экране размером с ноготь. Уменьши до 64px.
- **Вес.** Прогони через `pngquant`/`oxipng` — на Яндекс Играх время загрузки
  считают.

## Если фон запечён в пиксели

Модели отдают плоский растр, а JPEG альфу не умеет в принципе — шахматка из
превью приезжает пикселями. Дрону и руде это смертельно: они рисуются поверх
планеты и получат серый прямоугольник.

```bash
node tools/dechecker.mjs "исходник.jpg" assets/drones/scout.png 512 640
node tools/dechecker.mjs "исходник.jpg" assets/ores/dust.png   384 384
```

Скрипт заливкой от краёв вырезает шахматку (заливка, а не глобальный подбор
цвета — иначе выело бы серые пятна внутри самого дрона), съедает кайму от
JPEG-артефактов и уменьшает до нужного размера. Печатает процент вырезанного:
если близко к нулю — фон не опознан, и спрайт остался в коробке.

Планету через него гонять не надо — ей прозрачность не нужна.

Промпты для генерации — в `docs/asset-prompts.md`.
